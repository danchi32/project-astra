2. WHAT THIS SOFTWARE DOES - PLEASE READ
--------------------------------------------------------------------
The ASTRA Agent has two parts:

  * a Windows service that runs with system privileges and performs
    machine-level work; and
  * a tray application that runs in the signed-in user's session and
    provides the support chat.

It reports device inventory, performance telemetry, installed
software, services, Windows Update status and event log entries to the
ASTRA platform.

It EXECUTES REMEDIATION ACTIONS ON THIS DEVICE, drawn from a fixed
catalogue built into the agent, at the approval tier configured by the
organisation that enrolled it. Those tiers are:

  automatic          safe, reversible actions that may run without a
                     human approving each one, if your organisation
                     enables automatic approval
  approval required  runs only after one of your authorised people
                     approves that specific action
  admin only         higher-risk actions that only an administrator of
                     your organisation may approve, and which are never
                     dispatched automatically under any configuration

The agent executes ACTION IDENTIFIERS from its own built-in allowlist.
It does not accept or run arbitrary commands, and it rejects anything
outside that list - including instructions from Technomate's own
servers.

5. AUTOMATIC UPDATES
--------------------------------------------------------------------
The agent checks for updates periodically and applies them
automatically. Updates are cryptographically signed, and the agent
verifies the signature against a public key built into the installed
software before applying anything. An update that does not verify is
refused.

The private signing key is never held by the ASTRA backend, so a
compromise of Technomate's servers cannot push software to your
devices.
