## 2. Product copy: SAVIO

### Tagline (42 characters)

> AI System Administrator for Windows fleets

### Short description (146 characters)

> SAVIO is an AI System Administrator for Windows fleets. It diagnoses routine IT issues from live device data and fixes them within approval tiers.

### Medium description (≈420 characters)

> SAVIO is an AI System Administrator for businesses running Windows 10 and Windows 11 PCs. It gathers live evidence from each device, diagnoses routine IT issues and applies only permitted fixes, then verifies the result. Safe fixes run automatically; sensitive ones wait for IT approval, enforced in code. Built for lean IT teams managing roughly 25–500 Windows endpoints. 14-day free trial, no credit card required.

### Long description (≈1,450 characters)

> SAVIO is AI System Administrator software from Technomate IT-Solution, built for organizations that run Windows 10 and Windows 11 business PCs with a small IT team.
>
> Most of an IT technician's day goes into collecting context: what is installed, what changed, what the error says. SAVIO does that first. A lightweight Windows agent reports device health, installed apps, services, event logs and pending updates, and SAVIO uses that evidence, together with your own IT knowledge, before it proposes any fix.
>
> Fixes come from an allowlisted catalogue, never free-form commands. Each action has a tier enforced in code: routine fixes such as restarting a frozen Outlook, flushing DNS or clearing temporary files run automatically; heavier ones such as repairing Office, resetting the network stack or installing Windows updates need IT approval; and the most sensitive, such as disabling a local account during offboarding or blocking USB storage, are admin-only. After a fix, SAVIO checks the result. Every change and every agent command is recorded with who did what, to which device, and when.
>
> SAVIO supports IT administrators; it does not replace accountable human IT leadership. It is designed for teams managing roughly 25–500 Windows endpoints, including office and remote employees, and it can run alongside existing tools such as Microsoft Intune.
>
> Try it free for 14 days, no credit card required, or start with a guided pilot on up to 10 devices.

### Key features (one per line, for feature checklists)

- AI diagnosis from live Windows device telemetry (CPU, memory, disk, event logs, apps, services, updates)
- Self-healing from an allowlisted action catalogue
- Three approval tiers enforced in code: automatic, approval-required, admin-only
- Verification after every fix
- Full audit trail of changes and agent commands
- Windows update visibility per device, with approved installs and no forced restarts
- Secure offboarding: disable local accounts, block USB storage
- Knowledge base search over your own IT documentation
- Device inventory and reporting
- Web portal plus Windows agent; Windows 10 and 11

Primary: **IT Automation / AIOps**, **Endpoint Management**. Secondary: **Remote Monitoring and Management (RMM)**, **Help Desk / IT Service Management**, **Patch Management**.
